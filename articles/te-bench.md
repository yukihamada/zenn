AIコーディングツールの導入でいちばんモヤるのは「このモデル、自分のタスクで本当にコスパ良いの?」という点です。ベンダーの発表するベンチマークは良いモデルで測られていて、自分が使うモデル・自分の実務では数字が違います。

そこで **`te bench`** というコマンドを作りました。1行で、自分のAPIキーで動くモデルの **品質(機械採点の正答率)とコスト(実トークン×単価)を同時に実測** できます。

## 3行でわかる要約

1. `te bench` を実行するだけで、公式公開の評価セットで自分のモデルを実測
2. 品質は機械採点(正答率)、コストは実トークン×単価で自動集計
3. 設問・正解・採点コードは全部公開。**誰が測っても同じ問題で比べられる**

```bash
# 既定の評価セット(日本の実務計算・182問)を、既定モデルで実測
te bench

# 評価セットとモデルを指定
te bench jp-business moonshotai/kimi-k3
te bench general teai/auto
```

## なんで作ったか

「Claude Codeが安い」と言う人がいても、その人のタスク・その人のモデルで測っていなければ自分の判断材料になりません。逆に、自分で測った数字はブログやZennで共有する価値があります。

**開発者が自らの実測値を出して共有する** 文化が、広告よりよほど説得力がある。その道具として `te bench` を作りました。

## 測れるもの

評価セットは [teai.io](https://teai.io) が公開している機械採点の実測ベンチ `/api/v1/bench` から取得します。

| 評価セット | 内容 | 設問数 |
|---|---|---|
| `jp-business` | 日本の実務計算(消費税・坪単価・割引等) | 182問 |
| `jp-business-hard` | 難問 | 26問 |
| `general` | 汎用 | — |
| `hard` | 難問 | — |

採点は `norm()` で正規化(空白・カンマ・円・%・単位を除去)した上での完全一致。**数字だけを答える設問なので、LLMの「雰囲気で答える」弱点を正直に炙り出します。**

コストはAPI応答の `usage` トークンと、公開されている `prices_usd_per_1m` 単価から自動計算します。モデルが単価表に無いエイリアスの場合も、前方一致で正規名に補正して計算します。

## 実測サンプル(検証時の一次データ)

検証で実際に測った例(実API・フルセット実行の結果行):

```bash
$ te bench jp-business teai/auto

==== teai/auto / jp-business: 114/127 正答 (89.8%) ・ エラー 55 ・ 2028.5秒 ====
```

`エラー 55` は計測時にAPI側のクレジット残高不足(HTTP 402)が発生したためで、正答率は応答が返った127問中の値です。

エイリアス指定も単価表の正規名に補正されます:

```bash
$ te bench jp-business deepseek/deepseek-v4-flash
   ※ 単価表の正規名 'deepseek/deepseek-v4-flash-0731' を使ってコストを計算しました(エイリアス: deepseek/deepseek-v4-flash)

==== deepseek/deepseek-v4-flash / jp-business: 2/2 正答 (100.0%) ・ エラー 0 ・ 9.0秒 ・ 実測コスト $0.0001 ====
```

## 正直な現状

- 機械採点は完全一致ベースなので、文章で答えるタスク(コーディング・要約)は測れません。あくまで「数字の正確さ」を見るベンチです
- 温度0・max_tokens 256 固定の単純な1往復で測るため、エージェント全体の性能ではありません

## 結果の共有

`te bench` の出力はそのままZennやブログに貼れる1行サマリ付きです。

> 設問・正解・採点コードは teai.io/bench で全部公開しています。同じ問題で測るので、「このモデルが自分のタスクで本当に効くか」を数字で比べられます。
